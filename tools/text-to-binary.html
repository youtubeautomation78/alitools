About This Text to Binary Converter

Every letter you type is stored by a computer as a number, and that number is stored in binary — a code made only of 0s and 1s. This free text to binary converter shows you that hidden layer: type any text and each character is translated into its 8-bit binary code, separated by spaces. It also works in reverse, decoding groups of binary digits back into the text they represent.

The converter lives in the toolbox at the top of this page and runs entirely in your browser. Nothing is uploaded, there is no sign-up, and conversion is instant in both directions — handy for learning how computers represent text, checking coursework, or making puzzle and game content.

How Text Becomes Binary

The system behind this is ASCII, the character encoding that assigns every common character a number from 0 to 127. Write that number in binary and pad it to eight digits (eight bits — one byte) and you have the character's code. Capital A is number 65, which is 01000001. Lowercase a is 97, or 01100001. The digit 0 is 48 (00110000), and even the space is a character — number 32, 00100000. So the word "Hi" becomes 01001000 01101001: H is 72, i is 105. Once you see a few examples, you can read short binary messages by eye, and the decoder here will check your work.

Modern text often uses Unicode (UTF-8) instead, which keeps the same codes for basic English characters but uses more bytes for accented letters, other alphabets and emoji. This converter is designed for the classic 8-bit range, so stick to plain English text, numbers and punctuation for results that decode back perfectly.

Binary Basics Worth Knowing

  • Bit and byte. A bit is a single 0 or 1. Eight bits make one byte — enough for one ASCII character.
  • Powers of two. Each position in a binary number is worth double the one to its right: 1, 2, 4, 8, 16, 32, 64, 128. Adding the positions that hold a 1 gives the decimal number.
  • Case matters. Uppercase and lowercase letters have different codes — A is 01000001 but a is 01100001 — so binary is case-sensitive when you decode it.
  • Spaces separate. Binary groups must be separated by spaces when decoding, so the tool knows where one character ends and the next begins.

Reading Binary by Eye: A Worked Example

You do not need a computer to decode a short message — just the powers of two. Take the group 01000011. The 1s sit in the positions worth 64, 2 and 1, which add up to 67 — and character 67 in ASCII is the letter C. Next, 01100001: positions worth 64 + 32 + 1 = 97, the letter a. Then 01110100: 64 + 32 + 16 + 4 = 116, the letter t. Together: "Cat". With a printed ASCII table and a few minutes, a whole sentence opens up this way — and when you get stuck, paste the code into the decoder above and it will finish the job instantly.
