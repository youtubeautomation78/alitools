About This Tool

The alphabetical text organizer puts any list in perfect order. Paste a list of names, products, keywords, countries, songs — anything with one item per line — and sort it from A to Z or Z to A in a single click. You can also reverse the list, shuffle it into a random order (great for giveaways and quizzes), and delete duplicate lines automatically.

How to Use It

  1. Paste your list into the box, one item per line.
  2. Choose whether letter case should be ignored while sorting.
  3. Click Sort A → Z, Sort Z → A, Reverse, Shuffle or Remove Duplicates.
  4. Copy the organized list with one click.

Popular Uses

  • Teachers — alphabetical class lists and random student pickers.
  • Sellers — product, inventory and price lists in order.
  • Writers — glossaries, indexes and reference lists.
  • Everyone — cleaning messy lists with duplicates removed.
